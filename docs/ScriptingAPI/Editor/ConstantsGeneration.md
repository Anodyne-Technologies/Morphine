# Constants Generation API

- **Namespace:** `Anodyne.Morphine.Editor.Constants`
- **Assembly:** `Anodyne.Morphine.Editor`

Generates compile-time (`public const`) C# classes containing all runtime-queryable identifiers and hashes for any Unity `AnimatorController`.

---

## `AnimatorConstantsGenerator`

### Methods

#### `static string ResolveClassName(AnimatorController animator, MorphineConstantsConfig config)`
Resolves the sanitized C# class name using `config.classNameOverride` (if provided) or `animator.name`.

#### `static string GenerateSource(AnimatorController animator, MorphineConstantsConfig config = null)`
Returns the complete generated C# source string (`// <auto-generated>`) with `public const` definitions for all enabled sections in `config`:
- `Layers` (`Count`, indices, `Names`)
- `Parameters` (`Count`, `Bool`/`Float`/`Int`/`Trigger` hash constants, `Names`, and optional `Defaults`)
- `States` (recursive Layer / SubStateMachine classes with `ShortNameHash`, `FullPathHash`, `LayerIndex`, `Name`, `FullPath`)
- `Tags` (`Animator.StringToHash(tag)` + `Names`)
- `Transitions` (user-named transitions with `UserNameHash`, `NameHash`, `UserName`, `Name`)
- `Clips` (`const string` names of all referenced clips across states and recursive BlendTrees)

#### `static string GenerateAndWrite(AnimatorController animator, MorphineConstantsConfig config, out bool fileChanged)`
Writes the generated `.cs` file to `config.outputFolder` **only if the file content changed** (avoiding unnecessary Unity domain reloads) and imports the updated script via `AssetDatabase.ImportAsset`. Returns the project-relative asset path.

## `CSharpIdentifierSanitizer`

| Method | Description |
|---|---|
| `Sanitize(string raw, ConstantsNamingStyle style)` | Trims whitespace, tokenizes camelCase and non-alphanumeric delimiters, formats as `PascalCase` or `ScreamingSnakeCase`, prefixes leading digits with `_`, and escapes C# keywords with `@`. |
| `MakeUnique(string raw, HashSet<string> usedInScope, ConstantsNamingStyle style)` | Sanitizes `raw`, avoids `System.Object` member collisions, and appends `_2`, `_3`, ... on post-sanitization collisions within `usedInScope`. |
| `EscapeStringLiteral(string value)` | Escapes backslashes, quotes, and control characters for safe C# string literals. |

## `MorphineConstantsSettings`

Persists project-level default settings in `EditorPrefs` for the standalone right-click menu (`Assets > Create > Animation > Animator Controller C# Constants`):

- `static MorphineConstantsConfig LoadProjectDefaults()`
- `static void SaveProjectDefaults(MorphineConstantsConfig config)`

## Example

```csharp
using Anodyne.Morphine;
using Anodyne.Morphine.Editor.Constants;
using UnityEditor.Animations;
using UnityEngine;

public static class ConstantsApiExample
{
    public static void GenerateScreamingSnakeConstants(AnimatorController controller)
    {
        var config = new MorphineConstantsConfig
        {
            outputFolder = "Assets/Generated/Constants",
            namespaceName = "Game.AnimConstants",
            namingStyle = ConstantsNamingStyle.ScreamingSnakeCase,
            includeTransitions = false
        };

        string path = AnimatorConstantsGenerator.GenerateAndWrite(controller, config, out bool changed);
        Debug.Log(changed ? $"Wrote {path}" : $"Unchanged: {path}");
    }
}
```
