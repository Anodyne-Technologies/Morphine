# C# Constants & Runtime Playback

Hardcoding Animator parameter strings (`animator.SetFloat("Smile L", 1f)`) or layer indices is error-prone and incurs runtime string hashing. Morphine's **C# Constants Generator** emits 100% compile-time **`public const`** classes covering **every identifier and hash queryable via Unity's runtime `Animator` API**.

---

## Ways to Generate Constants

1. **From a `MorphineDrip` (`Build & Constants` tab or Inspector)**: Configures per-DRIP settings (`Output Folder`, `Namespace`, `Class Name Override`, `Naming Style`, section toggles) and optionally runs automatically whenever you rebuild the Base AC (**Auto-Generate Constants on Base AC Build**).
2. **From the Standalone Animator Aggregator**: Expand **C# Constants Generation** at the bottom of the preview pane to enable **Auto-Generate on Bake** or click **Generate Constants Now** for the baked output controller.
3. **Standalone Right-Click Menu (Any `AnimatorController`)**: Right-click any `.controller` asset in the Project window and select **`Assets > Create > Animation > Animator Controller C# Constants`** (uses project-level defaults saved in `MorphineConstantsSettings`).

*(To avoid unnecessary domain reloads, Morphine skips rewriting the `.cs` file on disk if its generated source is unchanged.)*

---

## Generated Sections & Identifier Sanitization

All names pass through `CSharpIdentifierSanitizer`, which safely handles whitespace, trailing spaces, punctuation, leading digits, C# reserved keywords, and post-sanitization collisions:

| Raw Animator Name (from `Plasto_Head`) | `PascalCase` (Default) | `ScreamingSnakeCase` |
|---|---|---|
| `"Cheek R Puff "` *(trailing space)* | `CheekRPuff` | `CHEEK_R_PUFF` |
| `"Mouth open wide"` | `MouthOpenWide` | `MOUTH_OPEN_WIDE` |
| `"Base Layer (UpperBody)"` | `BaseLayerUpperBody` | `BASE_LAYER_UPPER_BODY` |
| `"01_Blink"` | `_01Blink` | `_01_BLINK` |
| `"Smile-L"` & `"Smile_L"` *(collision)* | `SmileL`, `SmileL_2` | `SMILE_L`, `SMILE_L_2` |

## Driving `Plasto_Head` at Runtime

Because every hash is a compile-time `public const int`, you can use generated constants directly in `Animator.SetFloat`, `Animator.Play`, `Animator.SetLayerWeight`, and even `switch` statements with zero allocations:

```csharp
using UnityEngine;
using Morphine.Constants;

[RequireComponent(typeof(Animator))]
public class PlastoExpressionDriver : MonoBehaviour
{
    [SerializeField, Range(0f, 1f)] private float targetHappy;
    [SerializeField, Range(0f, 1f)] private float targetAngry;
    [SerializeField] private float blendSpeed = 8f;

    private Animator _animator;
    private float _currentHappy;
    private float _currentAngry;

    private void Awake()
    {
        _animator = GetComponent<Animator>();
    }

    private void Update()
    {
        _currentHappy = Mathf.MoveTowards(_currentHappy, targetHappy, Time.deltaTime * blendSpeed);
        _currentAngry = Mathf.MoveTowards(_currentAngry, targetAngry, Time.deltaTime * blendSpeed);

        // Zero-allocation hash calls against generated constants
        _animator.SetFloat(PlastoCombined.Parameters.Float.Happy, _currentHappy);
        _animator.SetFloat(PlastoCombined.Parameters.Float.Angry, _currentAngry);

        // Query runtime state or tag hashes cleanly
        AnimatorStateInfo baseState = _animator.GetCurrentAnimatorStateInfo(PlastoCombined.Layers.BaseLayer);
        if (baseState.tagHash == PlastoCombined.Tags.Locomotion)
        {
            // Character is in a locomotion state (e.g. Idle or Walk)
        }
    }

    public void MuteExpressionsLayer(bool muted)
    {
        _animator.SetLayerWeight(PlastoCombined.Layers.Expressions, muted ? 0f : 1f);
    }
}
```
